Privacy Policy — nextcloud-rclone

Last updated: 15 October 2026

What the app does

nextcloud-rclone is a personal tool used only by its owner. It uses the Google Drive API to make the owner's own Google Drive files visible on the owner's own private Nextcloud server.

Data accessed

The app accesses only the Google Drive of the account that signs in, which is the owner's own account. It reads and writes files in that Drive only when the owner opens or saves them through their Nextcloud server.

How data is used and stored

  • Google Drive data is used only to show and edit the owner's files in the owner's Nextcloud.
  • The login token is stored only on the owner's private server.
  • No data is sold, shared with third parties, or used for advertising, analytics, or training.
  • No data is collected from anyone other than the owner.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
